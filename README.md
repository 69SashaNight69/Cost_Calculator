# Smart Expense Tracker

A modern Android application for personal expense management built with **Kotlin** and **Jetpack Compose**.

The application helps users track daily expenses, organize them into categories, analyze spending statistics, store data locally, and manage personal finances in an intuitive interface.

---

## Features

- Add, edit and delete expenses
- Organize expenses by categories
- Expense groups management
- Financial statistics and analytics
- Google Maps integration
- Location-based expenses
- QR/Barcode scanning using ML Kit
- Bluetooth data transfer between devices
- Biometric authentication
- Modern Material 3 UI
- Offline-first application using Room Database

## Architecture

The project follows the **MVVM (Model–View–ViewModel)** architecture.

```
UI (Jetpack Compose)
        │
ViewModel
        │
Repository
        │
Room Database
```

This architecture keeps business logic separate from the UI and makes the project easier to maintain and extend.
